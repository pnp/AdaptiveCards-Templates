# Contribution Guidance

We welcome contributions.

## Sample submission requirements

- Create the sample in a descriptively named folder under `samples/`. Do not include terms such as `ace`, `card`, or `design` in the folder name.
- Start from [the sample README template](./samples/README-template.md), replace its placeholder content, and update the Designer link to reference the submitted sample folder and JSON file.
- Add an `assets/sample.json` file with metadata that matches the submitted sample.
- Store the sample preview image and other supporting images in the sample's `assets` folder.

Every sample README.md must end with the visitor tracking image in this format:

```html
<img src="https://m365-visitor-stats.azurewebsites.net/adaptivecards-templates/samples/sample-folder" />
```

Replace `sample-folder` so the URL suffix exactly matches the sample's repository path under `samples/`. This image is used for tracking views on individual samples.
